有刷直流电机通常被认为是最容易驱动的一类电机：只要给电机两端施加直流电压，电刷和换向器就会自动完成绕组换相，控制器只需要负责 PWM、方向和电流限制即可。但如果希望进一步实现闭环调速、堵转判断、行程控制或者位置估计，问题就会变成：在不增加霍尔传感器、光电编码器或磁编码器的情况下，能不能从电机本身的电气信号中推断出转速和位置？

这个问题就是本文想讨论的“有刷电机无感驱动”。这里的“无感”不是指完全不测量任何信号，而是指不额外安装专门的转子位置传感器。控制器仍然需要观察电机电流、电压或由这些信号经过滤波得到的脉冲，才能建立速度和位置反馈。

本文的思路来自对有刷和无刷电机控制方式的对比，也参考了 TI 关于有刷直流电机纹波计数的应用报告、DRV8214/DRV8234 数据手册和应用简报。文章中的图片来自 TI 公开文档，主要用来说明换向器、电流纹波和 RC_OUT 脉冲之间的关系；真正复刻时仍然需要根据电机型号、负载和供电条件重新测试。

有刷与无刷：区别不只是有没有电刷

电机按照换相方式可以粗略分为有刷电机和无刷电机。传统有刷直流电机的转子上有绕组，定子提供磁场，电刷和换向器负责在转子旋转时自动切换绕组电流方向。控制器看到的是一个相对简单的两线负载，方向由 H 桥决定，转速主要由平均电压、PWM 占空比和负载决定。

无刷直流电机则把机械换向器替换成了电子逆变器。转子通常使用永磁体，定子绕组需要由三相桥按照转子位置依次通电。由于没有电刷磨损、换向火花和机械触点，系统可以获得更高的寿命、更好的高速能力和更灵活的控制方式，但控制器必须知道转子当前的位置，至少要知道什么时候应该进行下一次换相。

因此无刷电机的无感控制通常围绕“估计转子位置”展开。低速时反电动势较弱，常用 I/F 或 V/F 开环强拖启动；速度建立后，可以切换到滑模观测器、龙伯格观测器、反电动势观测器、PLL 或其他状态观测器。对于低速和静止位置，也可以使用 HFI，即高频注入，通过电机磁阻凸极或高频响应差异估计角度。这些方法建立在三相绕组和电子换相的模型上，对无刷电机很有效。

有刷电机不太适合直接照搬这套路线。电刷和换向器会不断改变绕组连接关系，电流中包含明显的接触抖动、换向火花、机械偏心和负载相关成分。高频注入信号很容易被电刷接触变化和换向过程污染，观测器也很难保持一个固定的电机电气模型。不过，有刷电机的换向器同时也提供了一个新的观测入口：每次机械换相都会在电流或电压上留下可检测的纹波。

换向器为什么会产生电流纹波

换向器可以理解为一组随转子一起旋转的触点，电刷则是固定不动的滑动触点。转子旋转时，电刷会从当前换向片滑向相邻换向片，原本连接到某组线圈的电流会逐步转移到另一组线圈。在这个过程中，部分换向片可能出现瞬时短接、断开和重新导通，线圈电感又会阻止电流瞬间变化，于是电机输入电流中会出现周期性的尖峰或凹口。

这类纹波不是单纯的电源噪声，而是与电机机械转动存在相关关系的事件。转子每转过一个特定的机械角度，就会触发一次类似的换相过程。只要能够从电流波形中稳定地识别这些事件，就可以通过单位时间内的纹波数量估算转速，通过累计纹波数量估算相对位置。

电流波形中的纹波如何被识别

理想情况下，电机电流波形可以写成“平均直流分量 + PWM 纹波 + 换相纹波 + 机械和电磁噪声”。真正需要的信号只是其中与换相同步的那一部分。下图可以看到，有刷电机运行时电流波形上会重复出现尖锐的周期性变化，但这些变化并不是每一个都同样明显。

图 2：TI 应用报告中的有刷电机电流纹波示例。实际波形中同时存在平均电流、PWM 开关分量和换相导致的尖峰，算法需要先滤波再计数。图片来源：TI，ZHCADY5A。

一个可落地的模拟前端通常包含以下几部分：

  1. 电流检测元件：可以是低阻值分流电阻，也可以是集成驱动器提供的比例电流输出。分流电阻的压降为 V_SHUNT = I_M × R_SHUNT，阻值越大越容易检测小纹波，但损耗和发热也越大。
  2. 电流放大器：把毫伏级分流信号放大到 ADC 或比较器容易处理的范围。增益不能只按平均电流选择，还要为启动、堵转和换向尖峰保留输入输出余量。
  3. 带通或高通滤波器：去除电流的慢变化和一部分 PWM 载波，让换相纹波更加突出。只使用一个很重的低通滤波器可能把需要的尖峰也一起滤掉。
  4. 比较器或 ADC：比较器适合生成硬件边沿，ADC 适合保留波形并在软件中自适应判断。两者也可以组合，ADC 用于调试和阈值标定，比较器用于实时计数。
  5. 消隐和去抖：换相后的一小段时间内可能出现多个尖峰，必须设置最小脉冲间隔、数字消隐时间或迟滞，否则一次换相会被误计数成两个甚至多个纹波。

这里最关键的不是“把电流放大得越大越好”，而是让有效纹波和噪声之间有稳定的信噪比。TI 文档特别强调了低平均电流、低 PWM 占空比和启动浪涌对纹波计数的影响：电流太小时，纹波幅度接近噪声，算法容易漏计或多计；启动电流变化太快时，纹波可能被浪涌包络覆盖；负载突变时，滤波器响应速度又可能跟不上真实转速变化。

三种实现路线

路线一：使用集成纹波计数的电机驱动器

TI 的 DRV8214 和 DRV8234 是专门面向有刷直流电机的集成驱动器，除了 H 桥和电流调节外，还集成了 Ripple Counting、速度调节和堵转检测等功能。DRV8214 面向较低的电机供电范围，DRV8234 的电机供电范围更宽，适合更高电压的有刷电机系统。两者都提供 RC_OUT 输出，可以把内部纹波计数结果转换成脉冲或逻辑信号交给 MCU。

这种方案的优点是模拟前端、滤波、误差校正和一部分计数逻辑已经在芯片内部完成，MCU 不需要高速采样整条电流波形，只需要通过 I2C 配置参数并捕获 RC_OUT 脉冲即可。缺点是器件成本高于普通 H 桥，并且不同电机需要重新调整电阻参数、反电动势常数相关参数、滤波参数、纹波阈值和机械滤波时间常数。

路线二：外置分流电阻、放大器和 MCU

如果已经有一颗普通 H 桥或 MOS 功率级，也可以单独增加电流检测通道。硬件可以采用低边分流、高边分流或电机母线分流，前端接电流检测放大器，再把信号送入 MCU ADC。软件侧通过 PWM 同步采样、数字滤波和边沿检测提取换相纹波。

低边分流成本低、共模电压较小，但会让功率地发生随电流变化的压降；高边分流不容易影响地参考，但对放大器共模范围和布局要求更高。对于只关心速度而不需要特别精确转矩控制的应用，可以优先选择容易调试的低边方案，但要把 ADC 地、功率地和逻辑地的回流路径规划清楚。

ADC 采样的优点是能保留原始波形，便于观察不同转速、不同占空比和不同负载下的纹波形状。缺点是采样率、DMA 缓冲、CPU 负担和阈值算法都需要自己处理。建议把快速检测和慢速显示分开：快速路径只做去直流、带通、峰值检测和时间戳，显示路径再使用滑动平均或低通滤波，不能把慢速滤波后的速度值直接反馈给快速控制环。

路线三：串联小电感加电压尖峰检测

如果主要目标是低成本测速，而不是精确电流闭环，可以尝试在电机供电或 H 桥输出回路中串联一个小电感。电感的作用不是“凭空制造速度信息”，而是利用阻抗随频率变化的特点，减弱部分低频平均电流和高频 PWM 干扰的直接耦合，让换相瞬间的电压或电流变化更容易被观察到。

清华卓晴老师的视频中展示了类似思路：通过在直流电机回路中串联电感，滤掉一部分杂波，同时保留换相相关的电压尖峰，再使用比较器或示波器观察这些事件。对于成本敏感的系统，电感甚至可以尝试使用 PCB 走线绕线形成，但 PCB 走线电感的实际电感量、寄生电容、直流电阻和饱和特性受板材、线宽、走线形状和安装环境影响较大，只能作为实验方案，不能直接当作精密磁性器件替代品。

这条路线需要特别关注三个副作用。第一，串联电感会改变电机电流的上升速度和 PWM 电流纹波，可能影响低速转矩和堵转保护；第二，电感的 DCR 会带来额外压降和发热；第三，电感饱和后，信号形状会随电流变化，导致速度检测阈值不再固定。因此建议先用可更换的独立电感验证波形，再决定是否把它集成到 PCB 走线中。

来自交流测试的阶段性验证

在和技术大佬交流这个方向时，STC 的王煜顺也在同期进行了相关测试，后续已经把“串联电感 + 电机电压脉冲计数”的方案成功落地。从工程角度看，这个结果很有价值：它说明换相过程中产生的电压脉冲并不是只存在于示波器上的偶然波形，而是可以经过适当的硬件处理后，转换成 MCU 能够识别和计数的测速信号。

不过，这类结果需要明确验证边界。目前已经能够说明方案在原型和基础运行条件下有效可行，但实际带载能力、不同负载变化下的计数稳定性、低速启动成功率、堵转保护以及长时间投入使用后的可靠性还没有完成系统测试。因此，文章把它作为独立的阶段性旁证，而不是把它表述成已经完成产品级验证。后续仍然需要使用编码器作为真值参考，对空载、轻载、额定负载、突加负载、突卸负载和堵转状态分别记录电机电压脉冲、纹波计数、实际转速、电流和温升。

这个交流测试也进一步支持了本文的判断：对于有刷电机，直接套用无刷电机的高频注入或反电动势观测器未必是最合适的路线，但利用电刷换相带来的电流变化和电压尖峰建立专用观测链路，是一条具有实际落地可能性的方向。尤其是在不希望增加编码器、又需要获得基本速度信息的低成本执行器中，电感、比较器和定时器捕获可以组成一个相对简单的检测前端。

比较器最好增加迟滞和最小脉冲间隔。迟滞用于防止纹波信号在阈值附近来回抖动，最小脉冲间隔用于避免同一换相尖峰产生重复计数。这个间隔不能写成一个完全固定的经验值，因为高速和低速对应的纹波周期不同，更合理的做法是使用一个覆盖最高转速的硬件最小脉宽，再在软件中根据最近一段周期动态判断。

启动、低速和低电流是最大难点

无感有刷测速并不是任意状态都能工作。电机静止时没有换相事件，无法凭空得到绝对角度；刚启动时电流被 PWM 和绕组电感主导，换相纹波可能没有稳定形状；低速小负载时，纹波幅度变小，信噪比下降；堵转时电流很大，但没有新的有效换相，容易把电流尖峰误认为速度脉冲。

因此启动阶段不能直接依赖无感反馈。可以先使用固定方向、限流的开环 PWM 让电机转起来，等检测到连续几个纹波后，再启用速度估计。对于带减速箱或低速大转矩应用，可以使用一个外部限位或归零动作建立初始位置，然后把纹波计数用于相对位移和速度跟踪。

低速时可以延长统计窗口，例如累计多个纹波后再更新一次速度；但窗口太长会增加反馈延迟。若要用于闭环调速，应把速度估计的更新周期、滤波器时间常数和控制环带宽一起考虑。速度反馈只适合进入慢速外环，不能把一个抖动很大的纹波计数值直接拿去驱动快速电流环。

堵转识别则应同时使用电流和纹波两个条件：电流超过阈值且在一段时间内没有新的有效纹波，可以判定为疑似堵转；如果只有电流变大但纹波仍然存在，可能只是负载突然增加；如果只有纹波消失而电流没有上升，可能是电机断线、比较器故障或检测链路掉线。把多个观测量组合起来，比只看一个阈值可靠得多。

与编码器方案的对比

有刷电机无感测速最大的优点是减少外部传感器、连接器和机械安装件。对于小型执行器、打印机、风门、滑台、泵和低成本机器人关节，省掉一块编码器 PCB 可能同时降低 BOM、装配时间和故障点。TI 的专用器件还可以把纹波计数、速度调节、软启动和堵转检测集成到一颗驱动芯片中。

但它不能全面替代编码器。编码器通常能提供更高分辨率、更明确的方向和绝对或准绝对位置信息；纹波计数依赖电机内部结构和负载，低速、低电流、启动、换向火花和机械冲击都会影响计数质量。无感方案还需要为每种电机做参数标定，尤其是每转纹波数、滤波器、阈值、机械时间常数和错误校正参数。

因此可以按应用目标选择方案：只需要速度闭环和堵转检测时，优先考虑纹波计数；需要中等精度的相对位置时，可以在无感计数的基础上增加归零点；需要高精度绝对位置、高可靠低速控制或频繁正反转时，仍然应该使用霍尔、磁编码器或光电编码器。

建议的验证方法

第一版样机最好同时安装一个临时编码器，把编码器作为真值参考，而不是一开始就完全相信无感计数。测试项目至少包括：

空载匀速 编码器转速、纹波频率、PWM、平均电流 确认每转纹波数和速度换算
多档 PWM 低、中、高速下的漏计与多计次数 观察检测带宽和阈值稳定性
负载阶跃 电流、纹波周期、速度恢复时间 验证负载变化下的鲁棒性
低速运行 最低可检测转速、速度抖动 判断低速信噪比和反馈延迟
堵转测试 电流上升、纹波停止、保护时间 验证堵转识别和安全停机
正反转 纹波方向、计数复位、零速判断 检查方向切换和位置累计

评价指标不要只写“能测速”。建议至少计算速度平均误差、最大误差、纹波漏计率、多计率、从启动到有效测速的时间、负载变化后的恢复时间，以及堵转到关断的延迟。对于速度闭环，还要检查纹波测速值经过滤波后是否引入过大的相位滞后。

如果使用串联小电感方案，还需要额外记录电感两端电压、电机电流上升时间、稳态温升和不同电流下的波形变化。可以先用示波器确认换相尖峰的重复频率，再把信号接入比较器，最后才交给 MCU 定时器捕获。这样能把“没有波形”“有波形但比较器没翻转”“比较器翻转但软件误计数”这三类问题分开。

后续可以继续优化的方向

后续如果要把这个思路做成真正可用的模块，我认为可以沿着四个方向推进：

  1. 自适应阈值：根据平均电流、PWM 占空比和最近纹波幅值动态调整比较器阈值，减小不同负载下的漏计和多计。
  2. PWM 同步采样：让 ADC 采样点避开 MOS 切换瞬间，或者使用同步解调，把 PWM 载波和换相纹波分离开。
  3. 多观测量融合：把纹波频率、电流幅值、母线电压和电机模型结合起来，在启动、加速和堵转阶段使用不同判据。
  4. 集成磁性器件：先用独立小电感验证，再比较磁珠、电感、PCB 走线电感和电流互感结构的成本、带宽、饱和和一致性。

还可以把 MCU 内置比较器、定时器捕获和 DMA 结合起来，让快速边沿检测完全由硬件完成，CPU 只在低频任务中读取周期和状态。这样既能降低软件负担，也能减少中断延迟对测速精度的影响。对于资源较少的 8051、Cortex-M0 或 RISC-V MCU，这可能比持续采样整条电流波形更容易落地。

总结

有刷电机虽然没有无刷电机那样的三相电子换相结构，但电刷和换向器并不是只有损耗和寿命问题。换向过程中产生的电流纹波、电压尖峰和电流变化，本身就携带了转子运动信息。通过分流电阻、放大器、带通滤波器、比较器和定时器捕获，可以构建一个不依赖编码器的速度检测链路；通过累计纹波并配合归零点，还可以进一步获得相对位置。

TI 的 DRV8214 和 DRV8234 说明了这条路线已经可以被集成到专用驱动芯片中；外置模拟前端和 MCU 方案则更适合学习、低成本验证和已有 H 桥平台改造；串联小电感加换相尖峰检测则提供了一个值得实验的极低成本方向。它们的共同前提都是：纹波必须先被可靠地从 PWM、噪声、浪涌和机械冲击中分离出来，而且每种电机都需要重新标定。

因此，“有刷电机无感驱动”并不是简单地把无刷电机的观测器搬过来，而是要利用有刷电机独有的换相器结构建立新的观测模型。它不一定能替代所有编码器，但在速度闭环、堵转检测、相对位置和成本敏感的执行器中，确实是一条值得继续验证的工程路线。

STC8051U 学习型无刷电调

开源学习型无刷电机驱动平台，围绕逐飞 8051 电调固件、反电动势检测和栅极驱动展开。

UPDATED 2026.09.22STCBLDC

迁移来源：OSHWHub 开源工程
本项目定位为开源学习型无刷电机驱动平台，并非工业级量产电调。

项目简介

这是一个面向 BLDC 无刷电机驱动学习的开源电调案例板。当前硬件支持 3-6S 动力电池，使用逐飞开源的 8051 电调固件，经测试可以稳定工作在 30A+ 电流区间。

它的目标不是追求商业电调的极限性能，而是把一个能跑、能解释、能继续改进的无刷驱动平台做出来，让初学者能从电机原理、三相逆变、过零检测、栅极驱动、电源树和 PCB 布局几个层面理解电调设计。

快速规格

  • 项目定位：开源学习型无刷电机驱动平台。
  • 固件方案：逐飞开源 8051 电调固件。
  • 主控芯片：STC8051U。
  • 控制方式：无感六步换向，基于反电动势过零检测。
  • 输入电源：3-6S 动力电池。

上电警告

该工程没有在 PCB 上放置充足的板载母线电容。上电前务必在电源输入端焊接一个容量 220uF 以上的固态电容，否则电调极有可能上电损坏。

建议首次上电按下面顺序做：

  • 先不接电机，限流电源低电流上电，确认 10V 和 3.3V 电源正常。
  • 确认 MCU 供电、烧录接口和驱动芯片供电没有异常发热。
  • 接入电机前检查三相输出是否短路，确认 MOS 焊接方向和栅极网络无误。
  • 首次带电机运行时使用小油门、短时间测试，并观察电流和温升。

BLDC 与电调

直流无刷电机（Brushless Direct Current Motor，BLDC）通过电子换向替代传统有刷电机里的机械换向结构。BLDC 电机取消了电刷和换向器，将永磁体放在转子上、线圈绕组放在定子上。

图 1：BLDC 电机结构与星形（Y）连接示意。该图用于说明转子、定子绕组、位置检测与外部驱动电路之间的关系；本项目实际采用无感方案，因此不依赖独立位置传感器。

电机本身不会主动旋转，真正让它连续转动的是电调：

在这个链路中：

  • MCU 负责判断换向时机。
  • 栅极驱动芯片负责驱动 MOS。
  • MOS 组成三相逆变桥，控制三相绕组的电流方向。

所以电调本质上是一个由 MCU 控制的三相智能逆变器。

控制原理

常见 BLDC 电机有 A、B、C 三相绕组。六步换向控制会在每个时刻让两相导通、一相悬空。例如某一步中：

电调不断按 Step1 到 Step6 的顺序切换三相通电状态，形成连续旋转磁场，转子中的永磁体随磁场运动，从而实现旋转。

换相时机是 BLDC 控制的关键：

  • 换相过早：转矩降低、电流增大、电机发热。
  • 换相过晚：效率降低、转速下降。

因此电调必须知道转子当前大致位置。

无感过零检测

有感 BLDC 可以通过霍尔传感器或编码器直接获得转子位置。本工程采用无感方案，不增加额外位置传感器，而是通过检测电机自身产生的反电动势（BEMF）判断转子位置。

在六步换向中，悬空相不会参与驱动，但会因为转子旋转产生反电动势。电调通过比较悬空相电压和电机虚拟中性点电压，判断反电动势过零时刻。

图 3：EMFA / EMFB / EMFC 由三相端电压经分压网络得到，并与虚拟中性点 MID 进行比较。VS1 / VS2 / VS3 对应三相检测节点，供 MCU 判断悬空相反电动势过零时刻。

整体流程如下：

本工程采用电阻分压加 MCU 内部比较器完成过零检测。三相电压经过分压后输入比较器，以保证输入不超过 MCU 范围，同时保留足够的检测幅值。

需要注意：换相检测分压电阻不是固定值。如果要适配更高或更低的供电范围，需要重新调整 R10-R12 分压参数，并重新验证比较器输入范围和抗干扰能力。

主控选择

本工程采用 STC8051U 作为主控芯片。选择它主要是因为本项目的算法复杂度较低，使用的是：

  • 无感六步换向。
  • 反电动势过零检测。
  • PWM 调速。

8051U 相比 STM32G4 等电机控制 MCU 性能较低，但在基础无感六步电调中可以满足基本控制需求。它内部集成比较器资源，可以减少外部比较器需求，同时具备本设计所需的 PWM 资源，用于三相桥控制和换相切换。

图 2：STC8051U 主控连接关系。H1/L1-H3/L3 输出三相桥臂驱动信号，EMFA/EMFB/EMFC 与 MID/COMPO 用于反电动势过零检测，SIG_IN 用作外部油门/控制输入。

这个方案更适合：

  • PWM 输入。
  • OneShot 协议。
  • 基础六步换向学习。

不适合直接定位为：

  • 高性能 FOC 电调。
  • 高速数字协议电调，例如 DShot。
  • 大规模商业量产电调。

三相逆变桥

电池输出的是直流电，而 BLDC 电机需要不断变化方向的三相电流，因此电调需要完成 DC-AC 逆变。三相逆变桥由三个半桥组成，每个半桥包含一个高侧 MOS 和一个低侧 MOS：

三个半桥组合后形成 A、B、C 三相输出。六步换向本质上就是控制六个 MOS 按正确顺序导通，同时避免上下桥臂直通。

图 4：三相逆变器由 Q1-Q6 六个 TPH1R403NL 组成。Q1/Q3/Q5 为高侧 MOS，Q2/Q4/Q6 为低侧 MOS，VS1/VS2/VS3 是三相输出节点，GH/GL 信号由栅极驱动芯片输出。低侧栅极下拉电阻用于帮助关断并降低误导通风险。

栅极驱动

MCU 无法直接驱动功率 MOS，原因是 MCU 输出电压和电流能力有限，而 MOS 栅极需要快速充放电。如果直接接 MOS，容易导致：

  • MOS 开启速度慢。
  • 开关损耗增大。
  • MOS 发热严重。

因此需要栅极驱动器：

本工程采用 FD6288Q 三相栅极驱动芯片。该芯片集成三相高低侧驱动、自举驱动结构和死区控制，相比多个独立驱动芯片外围更简单、PCB 面积更小、成本更低，适合作为入门级 BLDC 驱动方案。

图 5：FD6288Q 左侧接收 MCU 输出的 H1/H2/H3 与 L1/L2/L3 控制信号，右侧输出 HO/LO 到三相 MOS 栅极。VB1/VB2/VB3 与 VS1/VS2/VS3 通过二极管和 1uF 自举电容形成高侧驱动所需的浮动电源。

高侧 MOS 的源极电压会跟随电机相线变化，普通 MCU 无法直接提供足够高的高侧栅极驱动电压，因此需要自举电路。自举电路通过二极管和自举电容储存电荷，在高侧 MOS 需要开启时抬高栅极电压。

驱动芯片还需要处理死区时间，避免高侧 MOS 尚未关闭时低侧 MOS 已经打开，从而造成 VBAT 到 GND 的瞬间短路。

MOS 选型

本工程使用 TPH1R403NL。MOS 选型不能只看最大电流，还需要关注：

  • VDS 耐压。
  • RDS(on) 导通电阻。
  • Qg 栅极电荷。
  • 封装散热能力。

6S 电池满电电压为 25.2V。实际产品设计通常建议 MOS 耐压留出足够裕量，例如选择 40V 以上器件。本项目定位为学习和竞赛使用，采用 30V MOS 做成本优化，但这也意味着抗浪涌和安全裕量更依赖布局、保护和使用条件。

MOS 导通损耗可按下面方向理解：

电流越大，低导通电阻越重要；Qg 越大，驱动难度越高，开关损耗也会受到影响。

下管栅极的 GS 下拉/泄放电阻用于帮助栅极寄生电容快速放电，加快关断速度。对电调来说，下管在制动和换向策略中经常承担更高负载，关断速度和直通风险都需要重点关注。

电源树

本工程电源结构如下：

10V 用于栅极驱动芯片，3.3V 用于 MCU 和检测电路。驱动芯片不建议直接接动力电池，原因包括：

  • 6S 满电可能达到 25.2V，可能超过部分驱动芯片安全供电范围。
  • 动力电池在启动、急加速和大负载时母线电压波动明显。
  • MOS 栅极最大耐压通常有限，驱动电压需要严格控制。

对本工程使用的 TPH1R403NL 来说，10V 栅极驱动可以让 MOS 较充分导通，同时避免驱动电压过高。

JW5026 用于将电池电压降到 10V，SPX3819 LDO 进一步生成 3.3V。LDO 电路简单、噪声较低，适合给 MCU、比较器和小信号检测电路供电。

图 6：DCBUS 通过 JW5026 降压生成 VGS。VGS 作为 FD6288Q 的栅极驱动供电，配合输入电容、10uH 电感、反馈分压和输出电容维持驱动电压稳定，避免直接把驱动芯片挂在动力电池母线上。

基础保护

BLDC 电调工作时会遇到电池插拔浪涌、MOS 高频开关尖峰和外部接口干扰。本工程定位为学习型 BLDC 电调，因此只加入基础保护。

当前重点保护思路包括：

  • 电源输入端加入 TVS，用于吸收插拔和开关瞬态高压。
  • 外部控制信号做限流和抗振铃处理，提高输入稳定性。
  • 输入接口避免悬空，减少 MCU 误触发。
  • 避免外部电源倒灌到内部 3.3V 供电。

输入电源保护

图 7：SMBJ26CA 跨接在 DCBUS 与 GND 之间。正常工作时 TVS 截止；当电池插拔、线束电感或 MOS 开关引起瞬态尖峰时，TVS 快速导通并把尖峰钳位到地，降低后级器件损坏风险。

信号接口保护

图 8：外部三线接口包含 GND、VCC 与 SIG_IN。SIG_IN 串联 100Ω 电阻用于限流和抑制振铃，10kΩ 下拉保证输入不悬空，B5819WS 用于降低外部电源倒灌到板内供电网络的风险。

如果用于更高功率或产品化场景，还需要进一步增加：

  • 过流保护。
  • 过温保护。
  • 防反接保护。
  • 预充电电路。
  • 更完整的母线电容和浪涌设计。

PCB 布局要点

电调 PCB 同时存在大电流功率回路、高频 PWM 开关信号和弱电检测信号，布局会直接影响 MOS 发热、电源稳定性、过零检测可靠性和电机运行稳定性。

功率回路需要满足：

  • 路径短。
  • 走线粗。
  • 回路面积小。
  • 电源和 GND 回流路径完整。

MOS 是主要发热器件，布局时应尽量靠近电机接口，增大散热铜面积，并通过过孔把热量导到背面铜皮。必要时可以增加散热片或提高 PCB 铜厚。

DC/DC 区域是主要干扰源之一，输入电容、开关节点、电感和输出电容之间的回路应尽可能短。反馈引脚 FB 属于弱信号，应远离 SW 节点和大电流线路。

过零检测属于弱信号部分，建议把检测电阻靠近 MCU，远离 MOS 高速开关区域，检测走线尽量短。

一个合理的电调布局通常分成三个区域：

对于普通两层 PCB，大电流路径优先使用顶层和底层大面积铺铜，底层辅助回流，信号线尽量避开功率区。

无感启动的分阶段验证

无感 BLDC 最容易被误判的地方是“电机能不能从静止启动”。电机停止时没有足够反电动势，比较器无法直接提供可靠的转子位置，因此启动必须经过预定位、开环加速和闭环接管三个阶段。预定位时只施加受限的相电压，把转子拉到已知的初始区域；开环加速阶段按照预设换相时间推进，逐步缩短换相间隔，让电机建立足够转速；当连续捕获到相位合理、间隔稳定的过零信号后，才把换相时序交给反电动势检测。

调试时建议把三个阶段的状态和关键计数器输出出来，而不是只观察电机是否旋转。预定位阶段要看占空比、保持时间和电流是否受限；开环阶段要看换相周期是否按预期递减、是否出现某一相长期不响应；闭环阶段要看过零有效次数、换相超时次数和当前检测相位。如果刚进入闭环就失步，优先检查比较器输入、虚拟中性点、分压比例和过零消隐时间，不要先把启动占空比继续加大。

推荐的首次上电顺序是：先不接电机确认 5V、3.3V 和 VGS 电源，再用低压限流电源接入一台小型无刷电机；先执行预定位，确认电流没有异常抬升；再用很低的启动占空比运行开环，观察三相波形和电机方向；最后才逐步延长闭环运行时间。每次改变 MOS、FD6288Q、自举电容或过零分压电阻后，都应重新做这套流程，因为功率级寄生参数变化会直接改变过零波形和启动窗口。

电流、低压和热测试边界

当前项目已经完成 30A 以上电流区间的稳定工作验证，但这个结果不能直接解释为任意电机、任意环境下的连续额定能力。测试报告至少应写明电池节数、电机型号、负载方式、输入侧电流、测试持续时间、MOS 温度、驱动电源温度和 PCB 环境温度。对于无感电调，还应记录启动成功率，因为空载长时间运行与带负载反复启动暴露的问题不同。

低压保护测试可以先在可控电源上缓慢降低 DCBUS，观察固件何时停止输出、是否会反复重启以及恢复电压是否有滞回；堵转测试则要严格限制持续时间，重点观察电流上升速度和 MOS 温升，不要用长时间堵转代替正常负载测试。温升测试建议分为短时峰值和稳态两类：前者关注换相瞬间和启动冲击，后者关注散热铜皮、MOS 封装和驱动供电在连续运行后的热平衡。

这些测试数据还能反过来指导 PCB 修改。如果过零信号在高占空比时被开关尖峰污染，应优先缩短检测回路、增加合理的 RC 滤波或调整采样时序；如果 MOS 温度高而驱动波形正常，应检查铜皮、过孔和 MOS 导通损耗；如果驱动供电在多次启动后下陷，则要回到 JW5026 的输入输出电容、地回流和自举网络重新核对。

项目价值

无刷电机驱动融合了电机原理、电力电子、嵌入式控制、PCB 设计、信号处理和硬件可靠性设计。本项目希望提供一个结构完整、成本较低、方便学习的 BLDC 驱动案例。

通过这个项目，学习者不只是得到一个“能跑的电调”，更重要的是理解：

  • 为什么需要三相逆变桥。
  • 为什么需要栅极驱动。
  • 为什么需要过零检测。
  • 为什么 PCB 布局会影响电机运行。

  • 优化驱动逻辑，减少对母线电容的硬需求。
  • 优化 EMC 和可靠性设计。
  • 尝试对于dshot等数字协议进行支持，优化抗干扰性。

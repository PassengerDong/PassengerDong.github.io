项目简介

本项目是一个专为第 21 届智能车竞赛“飞跃雷区”组别设计的高集成度、小型化核心控制板。针对竞赛车模空间受限、重量与重心控制敏感的问题，本设计舍弃了传统开发板“大而全”的冗余布局，对电源、接口和外围资源进行了精简。

板型对齐业内无人机飞控常见的 30.5mm 标准安装孔位，目标是在有限空间里提供稳定、紧凑、易于集成的飞控硬件。需要特别注意：本项目引脚分配不适配逐飞学习板，复刻时必须重新核对引脚表和接口定义。

图片与电源路径

电源输入直接来自电机驱动信号线，这样可以减少整车供电线束和额外电源模块。代价是飞控和电调联调时必须严格控制上电顺序，避免驱动端异常启动。

主电源轨使用 SY8303AIC 做宽输入同步降压，将高压电池输入转换为稳定 5V，给后级外设和核心电源提供输入。

核心供电没有沿用逐飞开源方案中的双路 DCDC，而是用两个 LDO 完成 3.3V 和 1.15V 供电。这样布局和走线更灵活，也便于在小尺寸飞控板上压缩面积。

硬件方案

主控与板型

主控使用 CYT4BB7，按本项目资料记录为双 M7 核 + 一个 M4 核，具备较强的运算能力和外设资源，适合承载视觉算法、姿态控制、传感器读取和竞赛状态机等任务。

板型参考无人机飞控生态，使用 30.5mm 标准安装孔位，便于与常见机架、减震柱和叠层结构配合。相比通用开发板，这块板更强调小尺寸、低重量和线束简化。

电源架构

输入级直接从电机驱动信号线取电，支持 2-6S 宽电压锂电输入。主降压使用 SY8303AIC，同步降压得到 5V，再由 LDO 分出 3.3V 和 1.15V，为 MCU 核心和外设供电。

这种结构压缩了电源模块数量，但也让飞控与电调之间的上电顺序更重要。联调时建议先确认 5V、3.3V、1.15V 都稳定，再接入电调控制信号和大电流负载。

接口与传感器布局

主控连接器采用 GH1.25mm 间距插座，在保证机械强度的同时减小体积。板载预留了距离检测、位移测量和声学提示单元接口。

IMU 使用外置小板思路，本项目原版使用 FPC 适配个人 IMU 小板。复刻时建议按自己的 IMU 模块改成 GH1.25 或其他更容易焊接和维修的接口。

IMU 设计留白

本核心板未直接集成陀螺仪，这个留白是有意为之：使用者可以根据控制策略选择外置高精度 IMU，例如 ICM 系列，并通过 I2C 或 SPI 与飞控通讯。

这样牺牲了一部分“一板即用”的便利性，但换来更高的传感器选择自由度，也便于根据车体结构把 IMU 放到更合适的机械位置。

与 STC 四合一电调配合

本飞控板已针对本人开源的 STC 四合一电调做了底层驱动适配和硬件接口对齐。两者配合时可以构成完整的动力与控制系统。

由于飞控电源取自驱动端，联调时建议严格遵守上电时序。个人建议给缓冲器增加下拉电阻，否则 STC 电调可能在上电阶段出现异常启动。

测试

本电路已经通过数月连续高负载上电测试，长时间运行稳定性表现良好。无出现明显问题，可支持长时间负载。

从本地软件工程看多核资源

与这块板对应的软件资料中可以看到 main_cm0plus.c、main_cm7_0.c、main_cm7_1.c 以及多核中断文件，说明硬件平台并不是只把 CYT4BB7 当作一颗普通单核 MCU 使用，而是为 CM0+、CM7_0、CM7_1 的分工预留了完整工程入口。复刻时不应只看芯片名称，还要确认所使用的启动文件、链接脚本、核间通信和下载配置是否与目标工程一致。

本地例程库还包含 UART、SPI、I2C、CAN-FD、DMA、GPIO、定时器、IMU、显示和无线通信等驱动目录。对竞赛车模来说，这些资源通常会被分成几条链路：底层驱动负责采集传感器和输出执行器，控制任务负责姿态、距离或运动状态，高层任务负责通信、调试和比赛逻辑。这样分层后，调试时可以先验证单个驱动，再验证任务调度，最后再接入完整车体。

上电与接口验证建议

这块飞控的电源来自电机驱动侧，建议严格按照以下顺序验证：

  1. 不接电机和摄像头，只给输入端上电，测量 5V、3.3V 和 1.15V。
  2. 确认主控可以通过 JTAG 或工程规定的下载器识别，再烧录最小 GPIO/UART 例程。
  3. 单独检查每个 GH1.25 接口的电源、地和信号方向，避免把外设的 5V 误接到信号脚。
  4. 先接 IMU、显示和距离传感器等低功耗设备，确认通信稳定后再连接电调和摄像头。
  5. 最后做电调联调，并在示波器上确认上电阶段没有产生误触发 PWM。

由于本项目把输入电源和电调放在同一系统里，飞控上电正常不代表电调上电时序就一定安全。建议给关键控制线增加明确的默认电平和下拉，必要时用缓冲器隔离，让飞控复位期间电调保持关闭。

外置 IMU 的实际取舍

外置 IMU 不是简单地把一根排线引出来。传感器位置、固定方式、地参考、电源噪声和机械振动都会影响姿态质量。原版使用 FPC 连接个人 IMU 小板，复刻成 GH1.25 后虽然更方便焊接和更换，但也要重新定义插座方向、地线数量、SPI/I2C 上拉和安装方向。

如果车体振动较大，建议把 IMU 小板放在结构刚度合适且远离电感、MOS 和电机线束的位置；如果使用板载 IMU，则要评估切割区、减震材料和相邻高速信号是否会改变传感器读数。文章中的“外置 IMU”应理解为一种系统级机械和电气取舍，而不是单纯的连接器替换。

与 STC 四合一电调配套时的注意点

飞控与 STC 四合一电调配套时，建议先把两块板分开验证：飞控侧确认 PWM/通信输出和安全默认态，电调侧确认四路功率级和下载配置，最后再用低压、限流电源连接。若电调在上电瞬间异常启动，优先检查飞控复位期间的控制线电平、缓冲器上下拉和电调使能逻辑，不要直接提高供电电压或反复插拔电池。

可取舍设计

板载 SY6280 电源路径管理芯片在特定应用场景下不是必需项。根据实测，移除该芯片不影响系统正常运行，可以根据 BOM、焊接难度和实际供电结构取舍。

如果队伍有双路供电需求，可以把输入端升级成理想二极管控制器，实现更平滑的电源切换。不过这会占用额外 PCB 面积，需要在可靠性和空间成本之间权衡。

复刻提醒

  • 本项目引脚分配不适配逐飞学习板，复刻前必须核对原理图和工程 pin 表。
  • 电源来自驱动端，飞控与电调联调前先确认上电时序。
  • FPC IMU 接口适配的是个人小板，通用复刻建议改成 GH1.25。
  • 30.5mm 孔位方便机械集成，但实际减震和重心还需要结合车架调整。
  • 如果后续改双电源输入，应重新评估电源路径芯片和 PCB 面积。

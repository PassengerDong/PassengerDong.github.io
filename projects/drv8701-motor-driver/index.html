基于 DRV8701 的双路有刷电机驱动

面向智能车和电赛场景的小体积双路有刷驱动板，在尽量压缩板卡面积的同时保留较大的电流余量。

UPDATED 2026.09.22TI有刷电机

迁移来源：OSHWHub 开源工程
本项目是一个基于 DRV8701 的小体积双路有刷电机驱动板，面向智能车、电赛和空间受限的中大电流驱动场景。

项目简介

现有开源有刷电机驱动方案里，常见问题是电流余量偏小，或者为了提高电流能力牺牲了板子体积。本项目围绕 DRV8701 设计双路有刷电机驱动，希望在较小 PCB 尺寸下提供更高的电流输出能力。

该驱动板可以覆盖智能车和电赛的大部分使用场景。实测在 12V / 10A 条件下运行正常且发热很小；补充测试中，16V / 20A 也可以正常运行，仅有轻微发热。板子采用单面元件布局，尺寸按小型驱动板语境整理为 49.5mm x 20.5mm。

图 1：DRV8701 双路有刷驱动实物图。板卡采用单面元件布局，便于焊接、检查和返修；核心目标是在智能车、电赛等空间有限的场景中，同时兼顾电流能力、散热表现和可复刻性。

设计背景

有刷电机驱动在智能车、电赛和小型机器人里仍然很常见，原因是控制简单、响应直接、调试成本低。但这类应用经常同时提出两个要求：

  • 体积要小，便于塞进车模或紧凑结构里。
  • 电流要足，能够承受启动、堵转、急加速等高负载瞬间。

很多入门级开源驱动板更偏向低电流验证，适合跑小电机，但在比赛或较大负载下容易发热明显；而电流能力更强的方案往往板子更大，安装和走线都不够灵活。因此本项目的核心目标是把双路驱动能力压缩到更小面积内，并通过布局和器件选择降低温升。

硬件架构

本项目以 DRV8701 为有刷驱动核心，外围配合功率级、供电、接口和保护电路，形成双路有刷电机驱动板。

双路设计的意义在于可以在同一块板上同时驱动两个有刷电机，适合差速车、智能车底盘、执行机构或需要左右轮独立控制的系统。单面元件布局也让焊接、测量、返修和课堂复刻更直接。

关键设计点

小体积与电流能力

49.5mm x 20.5mm 的板型让它可以安装在空间较紧的车模或电赛结构里。较大电流能力并不是只靠单个器件参数决定，还需要同时处理功率走线、铜皮面积、热路径和输入电容配置。

本项目的设计重点包括：

  • 缩短高电流回路，降低走线压降和寄生电感。
  • 增加功率路径铜皮面积，提高散热能力。
  • 将发热器件集中在便于导热和检查的位置。
  • 保持控制信号与功率开关节点的距离，降低干扰。

双路驱动

双路有刷驱动适合需要两个独立电机通道的场景。与单路驱动相比，双路设计需要更注意通道之间的热耦合、电源回流和瞬态电流叠加问题。

实际使用时建议根据负载情况确认：

  • 两路电机是否会同时启动或堵转。
  • 母线电源是否有足够电流余量。
  • 输入端电容是否能抑制电机启动带来的电压跌落。
  • PCB 安装位置是否有基本通风或散热空间。

单面元件布局

单面元件布局的优势是装配和调试更方便。对开源硬件来说，这一点很重要：使用者可以更容易地检查焊点、定位故障、替换器件，也便于在课堂或比赛调试现场快速维修。

代价是布局空间更紧张，需要在尺寸、走线宽度、散热铜皮和接口位置之间做取舍。本项目的价值就在于把这些约束压缩在一个较小板型里，同时保留较好的电流能力。

H 桥功率路径与控制边界

DRV8701 方案的核心不是单独一颗驱动芯片，而是“控制输入、栅极驱动、外部 MOS、母线电容和电机回路”共同组成的 H 桥系统。控制器给出方向和 PWM 后，DRV8701 负责把逻辑信号转换成适合功率 MOS 的驱动动作，外部 MOS 再把电池能量切换到电机两端。

因此调试时应该把问题拆成三层：第一层检查 MCU 或上位机给出的逻辑信号；第二层检查 DRV8701 的使能、故障和栅极输出；第三层检查 MOS 漏源波形、电机端电压和母线电流。若只在电机端看到“不转”，很难判断是输入命令、驱动供电、MOS 焊接还是电机本身的问题。

双路板还要额外考虑公共母线的瞬态。两路电机同时启动时，输入端电容首先承担快速电流变化，电源线和连接器承担平均电流，MOS 和铜皮承担热量。如果一路电机堵转，另一路仍然工作，公共地和电源回路上的压降可能会让另一通道出现误动作，所以两路通道既要分别验证，也要做同时启动和一侧堵转的边界测试。

测试数据的正确解读

当前记录中的 12V / 10A 和 16V / 20A 证明了板卡在对应测试条件下能够运行，但还不能直接等同于“任意电机、任意时间都能连续输出这个电流”。至少需要区分以下几种情况：

  • 电源输入电流还是电机绕组电流。
  • 电机启动峰值还是稳定运行电流。
  • 单路运行还是双路同时运行。
  • 测试持续几秒还是持续到热稳态。
  • 环境温度、散热方式和连接线规格是否一致。

后续建议增加热像仪或热电偶记录，把 MOS、DRV8701、输入端子、母线电容和 PCB 热点分别列出来。对于有刷电机，还要记录换向火花、堵转保护和 PWM 频率，因为这些因素会直接改变 MOS 的开关损耗和 EMI。

复刻与故障排查顺序

上电前先测 VBAT 与 GND、两路电机输出之间以及输出对地的静态电阻，确认没有焊锡短路。随后使用限流电源只给逻辑和驱动供电，确认 DRV8701 的逻辑电源、使能状态和故障脚符合预期，再接入单台电机。第一次运行不要把 PWM 直接拉满，应从低占空比、短时运行开始，观察电流是否随占空比平滑变化。

若单路正常、双路异常，优先检查公共电源回路、地回流、输入电容和散热，而不是先怀疑两颗 DRV8701 同时损坏。若两路都不转，则优先确认控制信号和驱动供电。把示波器波形、输入电流和器件温度一起记录，后续才能把“电路问题”和“电机/负载问题”区分开。

适用场景

  • 智能车底盘电机驱动。
  • 电赛小型执行机构或移动平台。
  • 需要较大电流但空间有限的有刷电机项目。
  • 有刷电机驱动原理、功率布局和热设计教学。

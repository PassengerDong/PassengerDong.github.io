# Somniomancer theme

This is an original, lightweight Hexo theme built for Direject's engineering
archive. It keeps the existing Home / Projects / Articles / Tags information
architecture while giving each route a cold-white editorial field, cobalt
structural lines, section marks and generous reading space.

The visual language follows the locally installed `Somniomancer` skill by
FanYUJ1U: sectional subjects, sampling, coordinate pressure, displacement and
blue flow. The theme does not reproduce Arknights, a character, a studio
campaign, or any third-party artwork. The hero SVG is original and is included
for personal, non-commercial learning/experimentation only; preserve the
Somniomancer author attribution when adapting this visual direction.

The previous `themes/arknights` theme remains untouched. A dated full snapshot
is stored at `themes/arknights-preserved-20260921`.
